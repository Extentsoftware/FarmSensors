## Key Features and Capabilities

### Performance Specifications
- **Flight Endurance**: 8-12 hours continuous
- **Operational Range**: 100+ km radius
- **Cruise Speed**: 50 km/h
- **Service Ceiling**: 3000m AGL
- **Payload Capacity**: 2-3 kg
- **Takeoff Weight**: 15-25 kg

### Surveillance Capabilities
- **Primary Camera**: 4K night vision with 30x zoom
- **Thermal Camera**: FLIR thermal imaging (320×240)
- **Wide-Angle Camera**: 4K, 120° field of view
- **Detection Range**: 100m (night vision), 200m (thermal)
- **Data Storage**: 1TB onboard + 2TB backup
- **Real-time Transmission**: 4K video transmission

### Autonomous Capabilities
- **Mission Planning**: Intelligent route planning
- **Autonomous Flight**: Fully autonomous operation
- **Adaptive Behavior**: Weather and condition adaptation
- **Mission Types**: Perimeter patrol, area survey, point monitoring
- **Coverage**: 100+ km² per mission

### Safety Features
- **Emergency Parachute**: Ballistic deployment system
- **Return-to-Home**: Automatic return capability
- **Geofencing**: GPS-based flight boundaries
- **Collision Avoidance**: Ultrasonic and LiDAR sensors
- **Dual Redundancy**: Dual flight controllers and GPS
