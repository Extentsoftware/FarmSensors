# Farm Surveillance Drone System

## Project Overview
A comprehensive design for a long-endurance surveillance drone system capable of autonomous night patrol operations for farm security and monitoring.

## System Components

### 1. [Main Design Document](farm_surveillance_drone_design.md)
Complete system specifications, requirements, and project overview.

### 2. [Airframe Design](airframe_design.md)
Fixed-wing UAV design with high aspect ratio wing for maximum endurance and efficiency.

### 3. [Power System](power_system_design.md)
Hybrid power system with lithium-ion batteries and solar panels for extended flight times.

### 4. [Avionics System](avionics_design.md)
Flight control, navigation, and communication systems with redundancy and safety features.

### 5. [Surveillance System](surveillance_system_design.md)
Night vision cameras, thermal imaging, and real-time data transmission capabilities.

### 6. [Autonomous Mission System](autonomous_mission_system.md)
Intelligent mission planning, execution, and adaptive behavior for farm surveillance.

### 7. [Safety Systems](safety_systems_design.md)
Comprehensive safety systems including parachute recovery, geofencing, and emergency procedures.

### 8. [Ground Control Station](ground_station_design.md)
Mission planning, real-time monitoring, and data management interface.

## Key Features

- **Long Endurance**: 8-12 hours continuous flight time
- **Night Vision**: 4K night vision and thermal imaging capabilities
- **Autonomous Operation**: Fully autonomous patrol missions
- **Solar Power**: Solar panel integration for extended flight times
- **Safety Systems**: Parachute recovery and comprehensive failsafe systems
- **Real-time Monitoring**: Live video feed and telemetry data
- **Weather Resistant**: Operation in light rain and moderate winds

## Technical Specifications

### Performance
- **Wingspan**: 3.8 meters
- **Weight**: 15-25 kg (including payload)
- **Cruise Speed**: 50 km/h
- **Service Ceiling**: 3000m AGL
- **Range**: 100+ km operational radius
- **Endurance**: 8-12 hours with solar power

### Surveillance Capabilities
- **Primary Camera**: 4K night vision with 30x zoom
- **Thermal Camera**: FLIR thermal imaging (320×240)
- **Coverage**: 100+ km² per mission
- **Detection Range**: 100m (night vision), 200m (thermal)
- **Data Storage**: 1TB onboard + 2TB backup

### Power System
- **Primary Battery**: 10.36 kWh lithium-ion
- **Solar Panels**: 2.5 kW peak power
- **Charging**: Ground station with solar array
- **Backup Power**: Emergency battery for critical systems
